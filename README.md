# ProdCalendar — виджет производственного календаря для Windows

Локальный виджет для системного трея: показывает производственный календарь на месяц,
подсвечивает рабочие/выходные/праздничные/сокращённые дни и считает нормы рабочего времени
(40/36/24 ч) за месяц и год.

Технология: **Windows PowerShell 5.1 + WinForms** (ничего ставить не нужно).
Полный план и обоснования решений — в файле `../План-виджет-производственного-календаря.md`.

## Запуск (после реализации)

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\ProdCalendar.ps1

## Данные

Порядок источников: **API isdayoff.ru → локальный кэш → вшитый офлайн-набор**.

- API: `https://isdayoff.ru/api/getdata?year=YYYY&pre=1` (параметр `pre=1` обязателен —
  без него не приходят сокращённые предпраздничные дни).
- Кэш: `%LOCALAPPDATA%\ProdCalendar\cache.json` (последний удачный ответ API).
- Офлайн: `data\offline.json` (по годам).

Обновить/добавить офлайн-набор на год:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\New-OfflineData.ps1 -Years 2026,2027

Скрипт сверяет 2026 с эталоном (ТК РФ + Постановление Правительства РФ от 24.09.2025 № 1466).

## Логи

`%LOCALAPPDATA%\ProdCalendar\prodcalendar.log`

## Ограничения

- Офлайн-набор за 2027 сгенерирован из API; при выходе официального постановления стоит
  перегенерировать и при необходимости сверить с ним.
- Сборка `.exe` и установщик не входят в текущий объём.
