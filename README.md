# Производственный календарь — виджет для Windows

Значок в трее рядом с часами: по клику открывает производственный календарь на квартал —
выходные, праздники и нормы рабочего времени. Ставить ничего не нужно, это скрипт на
PowerShell, который уже есть в Windows.

![Виджет производственного календаря: три месяца квартала, раскраска выходных и
подсказка на дне](assets/preview.png)

## Запуск

Дважды нажмите **«StartCalendar.vbs»** в корне проекта — значок появится в трее. Календарь открывается по клику на значок.

Автозапуск включается и выключается через правый клик по значку в трее: **«Добавить в автозапуск»** / **«Убрать из автозапуска»**.

## Что умеет

- **Календарь на квартал** — три месяца текущего квартала, кнопка `Развернуть ▲`
  разворачивает ещё на квартал (полгода).
- **Раскраска дней** — красный: выходной или праздник, янтарный со звёздочкой (`3*`):
  сокращённый день, фиолетовый кружок: сегодня.
- **Нормы рабочего времени** — рабочих и выходных дней и часы при 40-, 36- и 24-часовой
  неделе, в карточке каждого месяца.
- **Подсказки** — задержите курсор на дне, месяце или кнопке (см. картинку выше:
  день, месяц, статус дня).

## Управление

| Действие               | Как                                                             |
| ---------------------- | --------------------------------------------------------------- |
| Открыть / закрыть окно | Левый клик по значку в трее                                     |
| Закрыть                | `Esc` или клик в другом окне                                    |
| Другой квартал         | Кнопки `‹ Квартал` `Квартал ›`, колесо мыши или клавиши `←` `→` |
| Развернуть / свернуть  | Кнопка `Развернуть ▲` `Свернуть ▼` или клавиши `↑` `↓`          |
| Меню                   | Правый клик по значку: «Обновить данные», автозапуск, «Выход»   |

## Данные

Порядок источников: сервис [isdayoff.ru](https://isdayoff.ru) → кэш → офлайн-набор
`data\offline.json`. Что использовалось, видно внизу окна.

Добавить год в офлайн-набор:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\New-OfflineData.ps1 -Years 2027

Логи и кэш: `%LOCALAPPDATA%\ProdCalendar\`.
